# Гайд по сайту

## Для не программистов
Предполагается, что практически все необходимые изменения по содержимому (тексту и картинкам)
сайта можно внести не трогая код. Для этого надо
1. ткнуть в зелёную кнопку тут
2. ткнуть в кнопку "Codespaces" тут
3. создать новый codespace нажав на кнопку тут
4. дождаться пока он запустится
5. внести изменения (об этом позже)
6. найти иконку генератора и нажать "Save"
7. подождать
8. нажать на кнопку "Approve here"
9. откроется обратно интерфейс Github с комментарием с кнопкой ">>Preview<<"
10. по кнопке можно посмотреть как оно будет выглядеть
11. крайне рекомендуется в этот момент показать результат кому-то
12. нажать на кнопку "rebase and merge"
13. Подождать пока оно докатится до прода
